# v0.7 更新与验证

本轮按配置可靠性、诊断、状态、迁移和日常管理顺序实现。

- OpenCode / Pi：预览脱敏差异，应用前加密备份，写入后校验，恢复上次应用前的文件。保留无关字段与提供商；OpenCode 保留 JSONC 注释。
- 外部文件变化和预设变化会阻止使用过期预览；自定义配置位置暂拒绝写入，避免误改默认路径。
- Agent 列表区分尚未应用、已写入、预设改变、外部变化与已恢复。已写入不代表运行时功能通过验证。
- 地址检查不带密钥；模型测试需主动点击，发送少量测试内容且可能计费，不保存原始响应。
- 迁移包使用独立密码、scrypt 和 AES-256-GCM 加密。导入合并保留原绑定并备份本地加密库，不自动应用配置。
- 连接支持复制、归档与恢复归档；支持筛选已配置 / 本机发现的 Agent。

限制：ZCode 配置格式尚待验证，仍仅支持预设。其他目录工具不代表已有写入适配器。项目级配置可能覆盖全局默认模型；应用后应新开会话验证。目标工具按其格式将密钥存入本机配置，星桥库与备份使用系统加密。迁移密码不支持找回。

验证：16 项 Node 测试通过，涵盖加密、导入合并、诊断、配置保留、外部冲突和部分写入回滚。桌面测试在独立 userData 与 fixture-home 下通过 OpenCode / Pi 的 UI 预览、应用、恢复流程，并检查 1440 / 1024 宽度和 125% 缩放。未调用真实付费模型、未改动实际 Agent 配置。
