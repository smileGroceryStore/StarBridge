# 星桥 Starbridge v0.5

名称含义：连接 API、模型和不同工具的桥梁，星光呼应动漫暮色主题。

原创矢量图标使用拱桥、桥墩和四角星，提供 SVG、PNG 和含多尺寸的 Windows ICO。应用窗口、程序文件资源、安装器、桌面及开始菜单快捷方式均使用新品牌。

标题栏使用 Electron hidden titleBarStyle 与 Windows 原生 window controls overlay。40px 玻璃拖动区为系统按钮保留右侧空间，使用浅色符号与透明按钮背景，保留原生最小化、最大化、关闭及 Windows 窗口操作。

兼容更新保留原 appId 和 allsetting 数据目录，以继续读取既有加密套餐库与界面偏好，不重建或清空用户数据。

验证：6 项自动测试；1024/1440 与 125% 缩放无横向溢出。使用 Windows Computer Use 实际点击最小化、最大化、恢复和关闭；原生窗口截图位于 preview-v0.5-window.png。程序资源 ProductName/FileDescription 为 Starbridge，FileVersion 为 0.5.0。

新安装包名 Starbridge-Setup-0.5.0-x64.exe。本次升级保留既有安装位置，桌面和开始菜单旧快捷方式由安装器更新为「星桥 Starbridge」。
