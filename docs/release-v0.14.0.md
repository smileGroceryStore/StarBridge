# 星桥 StarBridge v0.14.0

- 扩展中心新增「模型定价」：内置从 models.dev 获取的 360 条有效参考价，支持搜索、新增、编辑、删除；单位为 USD / 每百万 Tokens。
- 支持从 models.dev 在线拉取目录，按模型与服务商筛选、分页勾选，只新增所选条目，保留已有定价和手动修改。
- 分别维护新增输入、输出、缓存命中、缓存写入四类单价，最多 8 位小数；未知缓存价格与明确免费分开处理。
- 用量页显示按模型估算的费用、四类 token 明细和未计价记录，独立保留日志报告费用，两者不相加。
- Claude / Pi 流式记录去重；Codex 按累计差值区分模型；Gemini 缓存不重复计入新增输入，思考 tokens 计入输出。
- 来源不明确且同名模型价格冲突、模型未记录、所需价格缺失时不自动猜价；阶梯模型标明只按基础参考价估算。

参考费用不代表套餐余额或服务商账单，不含长上下文阶梯、批处理、折扣与税费。此次不写入或修改目标工具配置，不发送日志、凭据或模型请求给 models.dev。

验证：87 项核心测试；隔离目录桌面操作、两套主题及 22 个弹窗固定按钮检查；桌面网络栈成功拉取 models.dev 在线目录。
