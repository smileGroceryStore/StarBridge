# v0.8 更新与恢复机制

- 备份与恢复入口：显示连接库备份、选择恢复缺失连接；保留当前连接，恢复项默认停用，不恢复工具绑定。手动清理超过 30 天且不在最新 10 份以内的可读库备份；Agent 备份不参与清理。
- 启动和恢复窗口焦点时检查未完成配置操作，显示顶部提示、文件状态和恢复入口。识别应用中断、恢复中断、遗留未提交记录、不可读记录及相关临时文件。
- 写入前保存加密日志；当前文件为操作前内容或该次写入内容才可恢复。外部改动阻止覆盖，恢复可重试。存在未完成操作时阻止该工具继续应用。
- 统一目录、模型页、工具详情和引导中的实际支持状态。
- 检查结果绑定密钥、端点、协议和模型摘要，配置改变显示过期；改备注保留原验证状态。
- 模型接口可编辑，ID 保持稳定；可删除未被 Agent 引用的模型，引用中的模型显示工具名称并阻止删除。
- 迁移导入先预览：跳过、另存副本或更新匹配连接，重复项默认跳过。更新保留已有绑定，破坏预设时阻止；确认前不修改库，预览 10 分钟失效。
- 卡片的复制、归档、诊断、删除收进原生“更多”，支持键盘展开。

适配范围：OpenCode / Pi 可实际应用。DeepSeek Harness 的官方 providers 文档与本机 0.2.0-rc.2 插件源码已研究，但运行 profile 与 patch/凭据存储关联仍需验证。ZCode 未确认当前版本持久化格式。两者保持预设，未扩大写入范围。

验证使用独立 userData、临时 home 和虚构密钥，不改真实 Agent 文件、不调用付费推理接口。Node 测试覆盖中断操作重启恢复、外部冲突、恢复中断、临时文件、库恢复和导入去重。桌面脚本覆盖启动提示、恢复、配置应用/还原、复制/删除/找回、重复导入跳过、1440/1024 宽度和 125% 缩放。

26 项 Node 测试通过；源程序与打包版桌面流程通过，包含模型接口编辑与重复导入跳过。预览截图使用临时演示数据。

库备份与 Agent 备份使用 Windows 系统加密；密码迁移包独立加密。加密损坏或权限问题需保留备份并检查，应用不会强制覆盖。
