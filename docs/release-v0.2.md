# v0.2 界面与套餐库

桌面导航重设计，新增 API / 套餐库作为默认入口，保留工具扫描与选择。

套餐字段：名称、厂商、计费类型、协议、接口地址、密钥、模型列表、备注、启用状态。支持新增、编辑、搜索、启停及工具分配预设。编辑密钥留空保留原值。停用保留绑定，禁止新增分配；同一工具分配到新套餐时替换原预设。

数据存储在 Electron 当前用户数据目录的 profiles.enc，使用 Electron safeStorage 调用 Windows 加密。整个库加密后写入临时文件再替换；加密不可用或原库无法解密时拒绝保存，不会静默覆盖。前端列表只获取 hasKey 标志，不返回密钥；无联网测试或请求发送。此设备上的加密库不是可直接跨设备使用的迁移包。

输入协议和计费类别均校验；远程地址要求 HTTPS，HTTP 仅允许本机。接口地址不允许用户凭据、查询参数和片段，减少误存密钥风险。

验证：6 项自动测试通过。隔离用户目录内使用虚拟凭据，通过实际桌面表单完成新建与分配；检查返回值未携带密钥。截图在 preview-v0.2.png，演示配置不写入正常用户库。

限制：启停与分配只作用于 AllSetting 中的预设。尚未验证远端 API 可用性，未计算真实余额或套餐额度，未写入工具配置。下一步为适配器预览、备份与应用。
