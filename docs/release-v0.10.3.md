# v0.10.3 工具目录与支持状态

应用设置原先仅循环显示三个写入适配器，其余工具没有说明；默认路径也只显示“默认用户目录”，容易误以为其他工具已支持自动配置却缺少入口。

- 展示全部 31 个工具，支持名称和工具 ID 搜索。
- OpenCode / Pi / Reasonix Studio 显示真实生效目录、默认或自定义来源、配置文件名及文件是否存在，保留目录选择和重置能力。
- 其余 28 项放入“其他已收录工具”，明确标注待适配，提供官方入口；不提供尚未生效的目录选择操作。
- 目录选择后仅刷新路径信息，不重置用户尚未保存的后台复选框。
- 主进程只返回路径和能力元数据，配置正文、密钥和文件解析错误详情不传入界面。
- 修正工具目录中 OpenCode、Pi 仍显示写入未实现的过时标记。

验证：47 项核心测试；桌面流程核对完整列表、搜索 Harness 自动展开待适配分组、未开放工具无写入控件，以及设置窗口无横向溢出。目录与支持列表改善不等于新增写入适配器，其他工具仍需后续逐个实现。
