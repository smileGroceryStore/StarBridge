# v0.9 后台运行与多连接

## 桌面与后台

- 系统托盘打开主窗口、进入 Agent 页、打开设置、切换模型预设方案及彻底退出。
- 默认关闭窗口隐藏到托盘；可独立设置最小化隐藏。首次关闭提示如何重新打开和退出。
- Windows 登录后后台启动为用户主动开启选项，默认关闭；后台不自动发起模型请求。
- 退出先等待当前配置、连接库和本机设置写入队列结束。再次启动同一程序唤起已有窗口；安装版 `--quit` 请求已有实例正常退出。
- 无托盘时关闭行为退回退出，不把用户困在无法打开的后台进程中。

## 配置与模型

- 修复应用失败回滚文件却未回滚活动记录的问题；恢复日志包含原活动记录。
- 修复 Pi 缩减模型后保留旧 enabledModels 模式的问题，保留非托管项。
- 诊断按请求协议判断实际输出，不把 choices:[{}] 当成功；区分无可见输出、认证、限流和不存在。
- 模型可选择继承默认端点/协议或独立覆盖。编辑连接显示继承影响范围。
- OpenCode / Pi 可选择一个默认连接及多个附加连接，分别选择模型；实际配置保留独立凭据与提供商命名空间。移除附加连接后，下次应用清理先前托管条目。
- 迁移包兼容旧单连接格式，并映射多连接引用。
- 支持本机自定义 OpenCode / Pi 配置目录；配置目录只在本机保存，不随迁移包复制。位置变化会使预览失效。符号链接路径仍拒绝自动写入。

## 常用操作

- 从现有 OpenCode / Pi 配置导入：只读取明确提供商、模型、协议和安全可解析的密钥。先预览、去重、确认；OAuth、命令/文件引用、自定义请求头暂跳过。未读取其他应用的登录数据库。
- 模板：Go Coding Plan、DeepSeek API、OpenAI Responses、Anthropic API 和本地兼容服务；标明来源与核验时间，无自动计费、余额假设或模型权限承诺。
- 收藏优先、名称及最近应用排序。最近应用时间为本机操作记录。
- 模型预设方案保存各 Agent 的连接和模型选择；切换不写入 Agent 配置、不冻结密钥/地址，仅当前设备保存，暂不随迁移包导出。

## 范围及验证

实际写入适配仍为 OpenCode / Pi。DeepSeek Harness、ZCode 配置存储契约未验证，保留预设；未实现协议代理和自动故障转移。

37 项测试通过，涵盖托盘生命周期、退出等待写入、元数据提交失败回滚、Pi 模型缩减、多连接凭据隔离与移除、目录变化、响应协议、继承、导入和方案。源程序桌面测试使用临时 userData/home 和虚构密钥验证应用恢复、双连接 UI、已有配置导入预览、方案、关闭隐藏和重新打开。截图使用演示数据。

未改动用户的真实 Agent 配置，未调用真实付费推理接口。升级前可在托盘选择“彻底退出星桥”。
