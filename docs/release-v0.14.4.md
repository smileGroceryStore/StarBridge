# 星桥 Starbridge v0.14.4

- Agent 模型和工作台增加明确的同步状态标签；同步异常、外部修改、同步中断及不支持同步使用醒目标识。
- ZCode 等未适配工具明确提示“仅保存预设，不写入工具”，配置弹窗说明接口、API Key 和模型不会自动写入。
- 工作台增加不支持同步的数量、导航待处理计数和筛选入口；同步失败在对应工具下展示原因。
- 保留 v0.14.3 的逐工具直接同步按钮，可备份并应用单项 API / 模型或共享资源。

ZCode 当前仍未开放配置写入，需要在 ZCode 内手动配置。文件已同步表示本机文件写入并核验，实际调用请在原工具的新会话中验证。
