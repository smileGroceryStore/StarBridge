# 星桥 Starbridge v0.13.0

本版完成配置状态、兼容性、常用工具、批量应用、完整迁移和发布维护六项优化。

## 配置工作台

启动默认打开工作台，统一展示待同步、文件已同步、外部修改/错误、未完成操作。编辑连接或共享资源后，侧栏更新待处理数量。每项可预览、编辑或恢复；待适配工具明确显示不支持，不伪装为已写入。

API 与共享资源同用配置文件时，核对另一模块写入的文件哈希及自身托管内容，避免误报外部改动。较旧模块的整体文件恢复点不再直接提供恢复，防止覆盖后续同步。

## 兼容性与工具适配

分配和预览时检查协议、默认模型、连接启用情况及 Go 会话要求。只读取已知安装位置的包版本，不执行发现的程序；无法确认版本时显示未知。写入和运行验证始终区分，不自动发起模型请求。

- OpenCode、Pi、Reasonix Studio：保留原有适配和多连接共存。
- Claude Code：Anthropic 兼容连接写入全局 settings.json；保留权限、其他设置；按服务使用 API key 或 bearer token，避免配置内两者冲突。
- Codex：Responses 连接写入 config.toml 的独立星桥 provider 和默认模型，保留用户 TOML 与 OAuth 文件。内联 provider 特殊结构不自动修改。密钥写入 provider 的直接 bearer token 字段，目标文件为本机敏感配置，备份系统加密。
- DeepSeek Harness：限已有 desktop profile，且已配置原生 opencode-go；更新默认模型与独立凭据引用，保留 native provider 以发送会话头。自定义路由、非 desktop、特殊 YAML 标签或未知结构会拒绝写入；YAML 可能重新排版。
- 新增上述工具的明确静态连接导入；OAuth、授权命令、专属请求头或不明确模型目录不自动复制。

Claude / Codex 的可选模型列表保存在星桥，本版仅写默认连接/模型，不改内置模型目录。适配与测试不代表所有软件版本、套餐或代理都能调用成功。

## 批量应用

勾选配置后先生成每项脱敏预览，确认后逐项加密备份、应用并汇报结果。单项失败不遮盖其余项。预设变化或文件出现外部修改会拒绝旧预览。同工具 API/资源顺序写入时，仅对星桥自身刚写入的共享文件刷新预览，并继续校验其他文件。

## 完整加密迁移

一个密码加密包包含连接、模型预设、MCP、完整 Skills 和提示词。导入时勾选要复制的条目，默认停用；已有预设不覆盖，资源重新分配，本机路径不迁入。模型预设仅在全部引用连接被选中时迁入。

两个库写入前保存带原始/目标哈希的加密恢复记录；失败时回滚，异常退出后在工作台提示恢复。发现外部更改则停止覆盖。OAuth、安装文件与历史对话不迁移。

## 维护与安装

- 工作台检查更新，访问本仓库 GitHub 正式版本；手动打开发布页下载安装，不静默下载执行。
- 脱敏诊断报告只含应用版本、工具 ID、状态与计数，不含密钥、配置正文、用户路径和对话。
- 设置备份保留期限（7/30/90/365 天），预览后再次确认清理；至少保留每类最近 10 份、未完成操作和当前恢复所需文件。不会按期限自动删除。
- Windows x64 安装包与 SHA256SUMS 一起发布。当前安装包没有代码签名。

## 验证范围

77 项核心回归测试通过，包括三个新适配器的保留/脱敏/恢复、重复应用恢复点、共享文件顺序同步、单项失败、完整迁移选择与 ID 重映射、双库回滚与中断恢复、备份保护、更新元数据和脱敏诊断。桌面使用临时目录和虚拟凭据验证工作台、批量应用、迁移选择、20 个弹窗在 960×700 下的关闭按钮/操作区/焦点与托盘。没有调用真实付费模型或写入真实 Agent 配置。
