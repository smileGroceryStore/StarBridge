# 第一版范围与验收

目标平台：Windows 优先，数据结构保留 macOS/Linux 扩展能力。

## 用户流程

打开软件 → 扫描本机 → 浏览全部工具 → 添加 API/套餐 → 勾选工具 → 预览 → 应用 → 检查结果。

未安装工具仍可收藏并预设绑定，状态显示“等待安装”；提供官方安装入口，安装后重新扫描。第一版使用安装引导，不静默批量安装。正式实现一键安装时需核验来源、版本、平台与安装结果。

## 开发顺序

1. 工具目录、只读扫描、手动添加路径、已安装/仅配置痕迹/未发现/检测失败状态。
2. API 与套餐库、协议和模型映射、密钥存储、单工具与批量分配。
3. 优先完成 OpenCode、ZCode、Claude Code 三个适配器，逐个验证后开放写入；Codex、Pi 和 DeepSeek Harness 随后接入。
4. 修改预览、备份、并发修改检查、恢复与错误报告。
5. 密码加密导出、跨设备导入、重新检测与重绑路径。

候选名单广泛收录；只有通过文件样本和实机验证的适配器才显示“可自动配置”。API 连接通过也不等于 Agent 的工具调用、流式输出和图片能力均可用。

## 验收标准

- 没安装的工具可搜索、选择、打开官方安装说明。
- 配置目录残留不会直接显示“已安装”。用户自定义安装路径可识别。
- 更换一个 API 后，可预览所有受影响工具，并选择应用范围。
- 写入不丢失无关字段；文件被外部修改时拒绝覆盖；失败提供逐项状态和恢复入口。
- 不支持的协议明确阻止应用；模型列表允许手动录入。
- 删除绑定不会自动注销官方账号，也不会误删用户自行添加的其他供应商。
- 日志和预览不泄露密钥；加密包错误密码无法解开，篡改能被检测。
- 新设备导入不复用旧设备绝对路径，重新扫描后再应用。

## 验证方式

适配器使用临时目录和去密钥配置样本测试字段保留、冲突拒绝与恢复。先做只读实机扫描，再由用户选择应用。安装指引、账户登录和配置写入能力分别验证。

首版暂缓本地协议转换、自动切换套餐、用量聚合、MCP/Skills 同步，以保证配置与迁移流程先可用。
