# v0.6 — 模型库与 Agent 独立模型

新增连接模型库：显示模型 ID、协议与模型接口；支持手动添加模型。OpenCode Go 支持从官方公开目录合并模型，不发送 API Key，不进行计费推理。目录中缺少已核验协议映射的模型暂不导入，结果显示跳过数量。公开目录不等于账户权限清单。

新增 Agent 模型页面：每个工具独立选择连接、默认模型、可选模型集合。Claude Code、Codex、ZCode、OpenCode、Pi 根据静态协议能力筛选；其他工具明确标注待核验。此筛选不代表端到端可用性验证。

同一 Go 连接可保存不同协议的模型，协议与 baseURL 保存在每个模型的 modelDetails。旧版加密库与 bindings 结构兼容，新增 toolModels，不回写或清空旧绑定。启用状态、模型引用与默认模型包含关系均在主进程验证；删除被 Agent 预设引用的模型会被拦截。

验证：8 项核心测试通过；隔离用户目录中使用虚拟连接，通过桌面模型添加表单和 Agent 表单，将 OpenCode 默认设为 example-model、Pi 默认设为 example-fast，同一连接的两项配置独立保存。1024/1440 与 125% 缩放无横向溢出。

限制：所有 Agent 选择仍为预设，尚未写入工具配置；没有用用户真实密钥发送推理测试。实际应用适配器、模型角色与跨连接多供应商组合留待后续。

本机升级结果：v0.6 安装完成；Go 官方目录合并 29 个模型，另有 8 个协议待核验项未自动导入。已有连接、密钥和工具绑定保留；未修改 Agent 配置文件。
